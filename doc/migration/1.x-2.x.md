# 1.x to 2.x

- `EnrichModel` and `EnrichModelList` no longer receive the `serverRequest` in the `context` parameter. If you still need it, write a custom handler with [`createTypedHandler`](../handler/typed.md).
- `createUpdateHandler` no longer strips `id`, `createdAt`, `updatedAt`, `_embedded` and `_links` from the request body. Use a `.strict()` input schema to reject them, or write a custom update handler if you need to ignore them silently.
- `createTypedHandler` no longer accepts `undefined` for a schema. Drop the property instead to get the same behavior.
